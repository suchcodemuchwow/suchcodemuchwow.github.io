# suchcodemuchwow

References for experienced engineers currently it is trying to cover react best practices and java for developers.

## Why this exists

Most documentation is either too basic or assumes deep familiarity with the ecosystem. These guides target the middle ground: experienced engineers learning something new who don't need hand-holding but do need the non-obvious parts explained.

## What's here

**React Best Practices**
Patterns and practices for production React applications. Covers component architecture, state management, hooks, performance, data fetching, TypeScript integration, testing, and accessibility. Assumes familiarity with React basics.

**Java for JS/TS/Go Engineers**
A guide for engineers coming from JavaScript/TypeScript or Go. Focuses on what's actually different: the type system, checked exceptions, generics, streams, and concurrency. Skips the introductory material.

## Running locally

```bash
pnpm install
pnpm dev        # localhost:3000
pnpm build      # static export
```
